# AGENTS

GitHub Action for SonarQube CE scan, analysis, and reporting. Written in
TypeScript, bundled to JavaScript via Rollup.

See [CONTRIBUTING.md](./CONTRIBUTING.md) for development, testing, and bundling
instructions.

## Project structure

| Path | Description |
| ---- | ----------- |
| `src/` | TypeScript source |
| `dist/` | Generated JavaScript (committed; don't review manually) |
| `__tests__/` | Vitest tests |
| `__fixtures__/` | Test fixtures |
| `action.yml` | Action metadata |
